## 一、D2-S 语法层：保证能渲染

- **代码块与方向**
  - 用 ```d2 包裹。
  - 首行写 `direction: down` 或 `direction: right`。
  - 验证：首行匹配。

- **容器与缩进**
  - 容器写 `节点名: {`，以 `}` 结束。
  - 内部缩进 ≥2。
  - 验证：容器行尾有 `:`，缩进一致。

- **属性与样式**
  - 属性写 `key: value`。
  - 样式写 `style.fill: "#fff"`。
  - 验证：无空值属性。

- **连接与标签**
  - 连接写 `A -> B: "标签"` 或 `A <-> B: "标签"`。
  - 验证：连接行含 `->`，标签在双引号内。

- **换行**
  - 需要换行时，标签必须用双引号。
  - 行间写 `\n`。
  - 单引号不用于换行。
  - 验证：双引号内出现 `\n`。

- **$ 转义**
  - 双引号内所有 `$` 写成 `\$`。
  - 典型：`bus.\$on`、`bus.\$off`、`\$emit`、`\$router`、`\$el`。
  - 单引号内 `$` 保持原样；同时需要换行和 `$` 时，用双引号 + `\$`。
  - 验证：双引号内裸 `$` 数量为 0。

- **转义表**
  - 双引号内 `\n` 换行，`\"` 双引号，`\\` 反斜杠，`\$` 普通 `$`。
  - 验证：无双引号内裸 `$`。

- **标点与形状**
  - 冒号、分号用半角。
  - shape 写 `rectangle|oval|cylinder|diamond|text`。
  - 验证：无全角 `：`、`；`，shape 值在枚举内。

- **输出前检查**
  - D2 可渲染。
  - 容器有冒号。
  - 属性有值。
  - 连接有标签。
  - 双引号内 `$` 已转义。
  - 验证：逐条打勾。

## 二、D2-C 内容层：保证内容一致

- **结构**
  - 唯一主入口：只写一个 `图0_总览`。
  - 多图编号：模块图写 `图1_...`、`图2_...`。
  - 可达：主入口连接所有模块图。
  - 验证：图0 唯一；图名连续无重名；每个模块图至少一条入边。

- **命名**
  - 节点 ID 用英文/拼音/下划线；label 用中文。
  - 事件写 `域:事件`，如 `sub-app:token-expired`。
  - 状态、API、测试用固定 ID：`ST-xxx`、`API-xxx`、`TC-xxx`。
  - 验证：ID 匹配 `^[A-Za-z_][A-Za-z0-9_]*$`；事件/状态/API/TC 均在契约中存在。

- **契约**
  - 事件契约：写 emit 方、on 方、payload、触发条件、幂等、清理时机。
  - 状态契约：写存储位置、初始值、变更条件、清除条件。
  - API 契约：写签名、参数、返回、异常、异步、幂等。
  - 测试映射：每个分支、事件、状态转换挂 `[TC-xxx]`。
  - 映射表：每个节点映射文件/类/函数；每条边映射调用/事件/状态转换。
  - 验证：events 覆盖所有 `EV-xxx`；states 覆盖所有 `ST-xxx`；apis 覆盖所有 `API-xxx`；tests 覆盖所有 `TC-xxx`；mapping 覆盖所有节点和关键边。

- **边语义**
  - 边标签写动作、事件/API、同步性、幂等、TC ID。
  - 异步边写 `await` 或 `nextTick`。
  - 验证：每条关键边含 `EV-` 或 `API-`，并含 `TC-`；涉及 `destroyApp`、`revalidateSSO` 的边有异步标记。

- **分支与状态**
  - diamond 出边互斥且穷尽，并有一条默认分支。
  - 每个 `bus.on` 有对应 `bus.off` 位置。
  - 每个全局状态有重置条件。
  - 多次触发定义锁或幂等标志，如 `isHandlingTokenExpired`。
  - 验证：每个 diamond 出边数 ≥2 且含默认分支；on/off 配对完整；states 表含清除条件。

- **工程约束**
  - 写清 Vue 版本、bus 实现、Wujie API 签名。
  - D2 label 只放标识和短语义；完整代码放独立代码块。
  - 验证：规格包首部有技术栈段；D2 内无多行代码。

- **输出前检查**
  - 主入口唯一。
  - 模块可达。
  - 契约覆盖。
  - 分支穷尽。
  - 异步/幂等/清理/重置已标。
  - 节点可映射。
  - TC 可追踪。
  - 验证：逐条打勾后才输出。
