# D2 输出规范

## 用法

- 顺序：元规则 → 语法层 → 内容层
- 分步：契约 → 图 → 代码 → 映射/测试

## 元规则

- **M-01 对账**：图中每个 ID 在契约中存在；代码引用的每个契约 ID 存在
  - 验证：图 ID ⊆ 契约 ID；代码引用 ID ⊆ 契约 ID
- **M-02 边分类**：边分为导航边和业务边；每条边归类唯一业务边字段见 C-05
  - 验证：无混合标签；导航边不挂契约 ID
- **M-03 术语**：默认分支=未匹配任何明确条件的兜底路径；否则分支=条件为否的明确路径；同步=同一执行单元内完成；异步=跨执行单元，标出等待方式
  - 验证：术语出现处语义一致

## 语法层

- **S-01 字符合规**：双引号内 `$` 写 `\$`、`"` 写 `\"`、`\` 写 `\\`；换行写 `\n`
  - 验证：双引号内无未转义的 `$`、`"`、`\`；多行标签在双引号内且含 `\n`
- **S-02 结构合规**：shape ∈ `rectangle|oval|cylinder|diamond|text`；容器行尾有 `:`；连接行含 `->` 或 `<->`；标签在双引号内
  - 验证：逐行扫描，全部合规

## 内容层

- **C-01 结构**：根图唯一；模块图编号；根图连所有模块图
  - 验证：根图唯一；图名连续；每个模块图至少一条入边
- **C-02 标识**：节点 ID 匹配 `^[A-Za-z_][A-Za-z0-9_]*$`；契约 ID 用统一前缀 + 序号
  - 验证：ID 正则通过；每个 ID 在契约中存在
- **C-03 契约**：
  - 交互：ID、参与方、数据、条件、幂等、生命周期
  - 状态：载体、初始值、变更条件、终止条件
  - 接口：签名、输入、输出、错误、同步性、幂等
  - 验证：契约覆盖所有 ID，字段无空缺
- **C-04 映射**：
  - 测试映射：分支/交互/状态转换 → 测试 ID
  - 节点映射：节点 → 实现单元；边 → 交互/状态转换
  - 验证：映射覆盖所有节点和业务边；每个分支/交互/状态转换有测试 ID
- **C-05 边标签**：业务边含动作、契约 ID、同步性、幂等、测试 ID；异步边标等待方式
  - 验证：字段完整；异步边含等待方式
- **C-06 分支**：diamond 出边互斥、穷尽、含一条默认分支
  - 验证：出边数 ≥2；含默认；条件两两互斥
- **C-07 配对**：每个订阅有取消；每个状态有终止；多次触发有锁
  - 验证：订阅/取消按 `名称 + handler` 配对；状态含终止条件；多次触发点有锁 ID
- **C-08 锚点**：首部写技术栈与关键签名；label 只放短语义；代码放独立代码块
  - 验证：首部有技术栈段；D2 内代码行数 = 0；代码块有语言标注
- **C-09 输出检查**：根图唯一、模块可达、契约覆盖、映射完整、分支穷尽、配对已标
  - 验证：逐条打勾
