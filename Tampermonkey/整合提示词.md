【D2 输出规范】

- 用法
  - 输出：只输出 D2 代码块；每个图一块；一次只出同一层级的图，先导航图，确认后出模块图
  - 标题：不用 `title`，用外层容器的 label
  - 自检：逐条满足 S/C 要求；序列图标题、连接引用 key、引号转义三项必查

- S 语法层
  - **S-01 标识**：节点 ID 匹配 `^[A-Za-z_][A-Za-z0-9_]*$` 且唯一；含保留字符（`. : ; & {} ! \`）时加引号；连接引用 shape 的 key，不写 label
  - **S-02 图与边**：导航图只有导航边且无标签，节点为模块；模块图只有业务边，可挂简短标签
  - **S-03 术语**：默认分支=未匹配任何明确条件的兜底路径；否定分支=条件为否的明确路径；同步=同一执行单元内完成；异步=跨执行单元，并标出等待方式；术语出现处语义一致
  - **S-04 字符**：双引号内 `"`→`\"`、`\`→`\\`、`$`→`\$`、换行→`\n`；含单引号用双引号，含双引号用单引号，两者都含时用双引号并转义；多行标签在双引号内且含 `\n`
  - **S-05 结构**：容器用 `}` 闭合；容器内属性换行或用 `;` 分隔；未指定 shape 的叶子默认 `rectangle`，shape ∈ `rectangle|oval|cylinder|diamond|text|sequence_diagram`；连接符 ∈ `-> <- <-> --`；标签在双引号内
  - **S-06 序列图**：外层容器写 `seq: "标题" { shape: sequence_diagram }`；同名子元素共享同一作用域；定义顺序即呈现顺序（参与者左右、消息上下）；同行声明多个参与者用 `;`
  - **S-07 保留字**：作 key 时加引号（如 `"label"`、`"width"`）；作属性名时裸写（如 `shape: ...`）
  - **S-08 非 ASCII**：保留符号用 ASCII 版本（如 `:` 而非 `：`、`;` 而非 `；`、`.` 而非 `。`）
  - **S-09 覆盖**：重复声明同一 shape 时合并；`key: null` 删除该节点或属性

- C 内容层
  - **C-01 结构**：导航图唯一；模块图编号连续；导航图连所有模块图；每个模块图至少一条入边
  - **C-02 边标签**：模块图业务边含动作、同步性；异步边标等待方式；标签简短
  - **C-03 分支**：diamond 出边数 ≥2、互斥、穷尽、含一条默认分支
  - **C-04 锚点**：label 只放短语义；D2 内不写代码（代码行数 = 0）

- header 只能直接出现在 window 内部。
